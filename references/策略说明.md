# 内置策略说明

共 **20** 个策略，分四类。

这些都是美股市场长期使用、且多数有公开研究支撑的范式。

> 所有输出都只是研究起点，不构成投资建议。每个策略的「局限」务必阅读。

# 趋势动量


## Minervini 趋势模板　`minervini`

**逻辑**：美股波段交易最广为人知的筛选框架：价格位于各条中长期均线之上、均线多头排列、200 日均线向上、已明显脱离 52 周低点且接近 52 周高点，相对强弱排名进入前 30%。

**条件**：
- `above_ma50` —— 价格站上 50 日均线
- `above_ma150` —— 价格站上 150 日均线
- `above_ma200` —— 价格站上 200 日均线
- `ma_bull_stack` —— 均线多头排列（20>50>200）
- `ma200_rising` —— 200 日均线向上
- `off_52w_low_30` —— 已自 52 周低点反弹 >30%
- `rs_strong` —— 相对强弱评级 ≥70
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`rs_rating`（降序）

**局限**：只在牛市或结构性行情中有效；熊市几乎选不出票，空结果本身就是风险提示。

```bash
python scripts/screen.py --strategy minervini --top 20
```

## VCP 波动收缩形态　`vcp`

**逻辑**：Minervini 的招牌形态：强势股在高位横盘整理时，波动区间逐次收窄、成交量同步萎缩，代表卖压衰竭，随后往往以放量突破结束整理。这里用「波动率收缩 + ATR 收敛 + 缩量 + 贴近高点 + 趋势向上」量化刻画。

**条件**：
- `vol_contracting` —— 波动收缩（20 日 < 60 日）
- `atr_tight` —— ATR 占比 <3%（波动收敛）
- `volume_dry_5d` —— 量能萎缩（5 日均量 <20 日均量的 0.8 倍）
- `near_52w_high` —— 距 52 周高点 <5%
- `above_ma50` —— 价格站上 50 日均线
- `ma_bull_stack` —— 均线多头排列（20>50>200）
- `rs_strong` —— 相对强弱评级 ≥70
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`rs_rating`（降序）

**局限**：量能萎缩用 5 日均量与 20 日均量之比来判断，而非当日量比——单日成交量会被三巫日、指数调仓、财报日等一次性事件严重干扰。VCP 的精髓是「收缩次数与幅度逐级递减」，纯用当日快照只能近似。形态本身不给方向，必须等放量突破确认，否则可能向下破位。

```bash
python scripts/screen.py --strategy vcp --top 20
```

## Darvas 箱体突破　`darvas_box`

**逻辑**：达瓦斯箱体法：股价在箱体内震荡后放量突破箱顶。这里以「创 52 周新高 + 显著放量 + 趋势确认」作为突破信号。美股没有单日涨跌幅限制，突破后价格可连续运行，这类策略因此更易执行。

**条件**：
- `at_52w_high` —— 创 52 周新高
- `volume_surge` —— 放量：成交量 >20 日均量 2 倍
- `adx_trending` —— ADX>25，趋势明确
- `above_ma50` —— 价格站上 50 日均线
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`vol_ratio`（降序）

**局限**：突破失败（假突破）比例不低。原法依靠箱体下沿止损控制风险，本项目不提供止损执行，使用时须自行设定离场规则。

```bash
python scripts/screen.py --strategy darvas_box --top 20
```

## 双动量　`dual_momentum`

**逻辑**：Antonacci 的双动量框架：同时要求绝对动量为正（12 个月自身上涨）与相对动量领先（跑赢大盘），再加长期趋势过滤。绝对动量用于在熊市中自动离场，是它相对纯相对动量的关键改进。

**条件**：
- `mom_12m_pos` —— 12 个月动量为正
- `mom_12_1_top` —— 12-1 动量为正（学术口径）
- `rs_leader` —— 相对强弱评级 ≥80（跑赢大盘）
- `above_ma200` —— 价格站上 200 日均线
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`rs_rating`（降序）

**局限**：动量因子长期有效但存在「动量崩溃」：市场由跌转涨的拐点处回撤极大。

```bash
python scripts/screen.py --strategy dual_momentum --top 20
```

# 质量价值


## Piotroski 高分股　`piotroski`

**逻辑**：Piotroski F-Score 用九项财务指标的逐年变化判断基本面是否在改善：盈利性、现金流质量、杠杆与流动性、运营效率。得分 8 分以上代表财务状况稳健且在持续改善。原始研究发现该指标在低市净率股票中区分度最强，故叠加估值条件。

**条件**：
- `f_score_8` —— Piotroski F-Score ≥8（财务稳健）
- `pb_below_3` —— 市净率 <3
- `profitable` —— 盈利（TTM 净利润为正）
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`f_score`（降序）

**局限**：F-Score 衡量的是「改善趋势」而非「绝对优秀」，一家从很差改善到一般的公司也可能拿高分。

```bash
python scripts/screen.py --strategy piotroski --top 20
```

## 神奇公式　`magic_formula`

**逻辑**：Greenblatt 的组合：同时看资本回报率与息税前收益率，两项排名相加取最优。思路是「用便宜的价格买回报率高的生意」。

**条件**：
- `magic_top100` —— 神奇公式综合排名前 100
- `profitable` —— 盈利（TTM 净利润为正）
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`magic_rank`（升序）

**局限**：原版用「净营运资本＋净固定资产」算资本回报，免费数据拿不到净固定资产，本项目用「总资产 − 流动负债」近似，结果与原版会有差异。该公式对金融股与强周期股不适用。

```bash
python scripts/screen.py --strategy magic_formula --top 20
```

# 事件结构


## 财报后漂移　`pead`

**逻辑**：学术上被反复验证的 PEAD 现象：财报公布后，价格倾向于沿财报当日的方向继续漂移数周。这里捕捉「刚公布财报 + 跳空高开 + 趋势未破」的组合。

**条件**：
- `pead_window` —— 财报后漂移窗口（1~45 日）
- `gap_up` —— 跳空高开 >2%
- `above_ma50` —— 价格站上 50 日均线
- `rs_strong` —— 相对强弱评级 ≥70
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`rs_rating`（降序）

**局限**：完整的 PEAD 需要分析师预期数据来判断是否超预期，而预期数据没有稳定的免费来源，因此这里用「跳空方向」近似替代，效果会打折。

```bash
python scripts/screen.py --strategy pead --top 20
```

## 机构重仓股　`inst_favorite`

**逻辑**：13F 显示机构持有家数众多、持股占流通市值比例高，同时技术面处于上升趋势。机构集中持有意味着流动性好、研究覆盖充分。

**条件**：
- `inst_many_holders` —— 机构持有家数 >1000
- `inst_own_high` —— 机构持股占市值 >70%
- `above_ma200` —— 价格站上 200 日均线
- `rs_strong` —— 相对强弱评级 ≥70
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`inst_holders`（降序）

**局限**：13F 每季度披露且滞后 45 天，反映的是上季度末的持仓，不是当前持仓。机构高度拥挤的股票在风格切换时也更容易被集中抛售。

```bash
python scripts/screen.py --strategy inst_favorite --top 20
```

## 期权异动　`unusual_options`

**逻辑**：期权名义成交量达到正股成交量两倍以上，同时正股放量上涨——通常意味着有资金在用期权表达方向性观点。

**条件**：
- `option_unusual` —— 期权异动：名义成交超过正股成交量
- `volume_up` —— 温和放量（>1.5 倍）
- `above_ma50` —— 价格站上 50 日均线
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`opt_stock_vol`（降序）

**局限**：期权异动同样可能来自对冲、备兑开仓或做市商调仓，并不必然是看多。需结合认沽认购比与价格方向一起判断。

```bash
python scripts/screen.py --strategy unusual_options --top 20
```

## 轧空候选　`short_squeeze`

**逻辑**：做空成交占比显著高于自身常态，同时价格站上 20 日均线并开始放量，空头回补可能推动价格加速上行。

**条件**：
- `squeeze_candidate` —— 轧空候选：做空占比高且价格站上 20 日线
- `short_spike` —— 做空占比异常放大（Z>2）
- `volume_up` —— 温和放量（>1.5 倍）
- `liquid_10000000` —— 日均成交额 >1000 万美元

**排序**：`short_ratio`（降序）

**局限**：美股特有玩法，风险极高：轧空来得快去得也快。且做空成交占比受做市商对冲干扰，绝对值高并不等于市场看空。

```bash
python scripts/screen.py --strategy short_squeeze --top 20
```
